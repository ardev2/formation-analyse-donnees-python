# Corrigé du TP bonus A

Une solution complète : filtres par région, période et catégorie, chiffres clés, évolution mensuelle, objectifs, meilleurs produits et téléchargement de la sélection en CSV.

L'application lit les données du dossier `ressources/` du TP : on la lance depuis le dossier parent.

```bash
cd ..
uv sync
uv run streamlit run corrige/app.py
```
